
# Task 1 – Daikibo Telemetry Data Analysis Using Tableau

## 1. Introduction

This task was completed as part of the Deloitte Data Analytics Virtual Experience Program.

The project focused on analyzing industrial telemetry data from Daikibo factories to understand equipment performance and identify downtime patterns across different factories and device types.

## 2. Business Problem

Manufacturing organizations depend on the continuous operation of industrial equipment. Unexpected equipment failures and downtime can affect productivity and operational efficiency.

The objective of this analysis was to examine telemetry information and identify how equipment downtime was distributed across factories and device categories.

## 3. Project Objectives

- Analyze industrial equipment telemetry data.
- Understand equipment health status.
- Identify downtime across different factories.
- Compare downtime across different device types.
- Create visualizations to communicate analytical findings.
- Develop an interactive dashboard for exploring factory-level performance.

## 4. Dataset Description

Dataset: Daikibo Telemetry Data

Format: JSON

The dataset contains telemetry information related to industrial equipment and its operational status.

The data was used to analyze equipment health and downtime patterns.

## 5. Tools and Technologies

- Tableau
- JSON
- Data Visualization
- Calculated Fields
- Interactive Dashboards

## 6. Analysis Performed

The following visualizations were developed:

### A. Down Time per Factory

Analyzed equipment downtime across different factories to understand variations in operational performance.

### B. Down Time per Device Type

Compared downtime across different equipment categories to understand which types of devices experienced operational issues.

### C. Interactive Dashboard

Combined both visualizations into a single dashboard.

The factory visualization was configured as a dashboard filter, allowing factory-level selection to update the device-type analysis.

## 7. Deliverables

- Factory-wise downtime visualization.
- Device-type-wise downtime visualization.
- Interactive Tableau dashboard.
- Analytical observations based on telemetry data.

## 8. Expected Business Value

The analysis helps illustrate how telemetry data can support equipment monitoring, operational performance evaluation, and identification of areas requiring further investigation.

## 9. Conclusion

This task provided practical experience in using Tableau to analyze industrial telemetry data, create calculated fields, develop visualizations, and communicate operational insights through an interactive dashboard.
