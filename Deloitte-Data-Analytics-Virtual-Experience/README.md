
# Deloitte Data Analytics Virtual Experience

## Project Overview

This repository documents my hands-on experience completing the Deloitte Data Analytics Virtual Experience Program.

The project demonstrates practical exposure to data analytics, data visualization, dashboard development, data interpretation, and business problem-solving through two assigned tasks.

The assignments provided an opportunity to understand business requirements, analyze datasets, develop visual representations of data, and communicate meaningful insights.

## Project Objectives

- Understand real-world business problems through data analytics.
- Prepare and analyze structured and semi-structured datasets.
- Develop meaningful data visualizations and dashboards.
- Identify patterns and operational inefficiencies.
- Translate analytical observations into actionable business insights.
- Strengthen technical and analytical problem-solving skills.

## Project Structure

### Task 1 – Daikibo Telemetry Data Analysis
Analyzed industrial telemetry data to understand equipment downtime across factories and device types using Tableau.

Key activities:
- Understanding telemetry data.
- Creating calculated fields.
- Analyzing downtime across factories.
- Analyzing downtime across device types.
- Developing an interactive dashboard.
- Applying factory-level dashboard filtering.
